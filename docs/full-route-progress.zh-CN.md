# 全塔破纪录路线推进日志（未完成）

本轮主线是生成并验证完整24层通关路线。以下是工程进展，不是完成新的全塔里程碑，也不是世界纪录。

## 已实际验证到哪里

未修改的既有Ver1.12候选在官方Ruffle0.7.1中，从菜单、仙子开场开始，通过普通浏览器鼠标/键盘输入执行了665个关键动作。使用真实时钟和自然随机数，无冻结日期、指定种子、存读档、重开或游戏变量写入。

- 普通输入11777次，最高到十一层，随后救小偷、开放二层铁门，并取得二层钢剑和钢盾。
- 最终位置在二层：495HP、342攻、205防、5级，黄/蓝/红钥匙1/1/0，金币45、经验53。
- 原版游戏计时从0推进到560秒。
- 107场战斗、653次真实抽样，逐战用独立帧级数值模型复核，全部相同。
- 用原版受限字节码解释器从自然开局重建同一语义动作序列，在最不利抽样199下得到450HP，全部非HP资源与实际回放相同；每个检查点实际HP均不低于该数值路线。
- 只读观测器的根作用域检查始终成立。尚未为这条新长续程完成无观测器对照；旧M6/M7/M8对照不自动推广到本路线。

本轮没有24层结局、没有同规则纪录超分，也没有平台认证。[数值证据](../experiments/full-route-prefix11.json)及可重复校验程序随代码保存；原版地图数组、截图、对白及原版动作体仍留在忽略目录。

## 新的路线工具

`OriginalRoute`从固定原版初始化读取数据，逐次执行已审阅的原版移动、楼层切换、战斗及剧情完成节点。四个函数调用和具体剧情帧采用白名单；未知代码/调用仍拒绝。界面动画、提示关闭、对话翻页和时钟在这个数值工具中明确是边界适配，所以它自身不构成游戏原生回放。

`Guidance`在真实快照上用资源多样性束搜索提出下一个剧情/装备检查点，并逐步与上述原版字节码核对。它不证明穷尽，失败只表示未找到候选。击败16/19/21层关键Boss会改变全局状态，因此在相应边界停止并重新获取快照，不能继续使用旧敌人表。

`fullgame_replay.mjs`在真实播放器中读取当前楼层地图，走普通按键，处理商店和剧情，并记录完整输入、资源和战斗抽样；按实际结果检查候选。`audit_fullgame.py`从实际语义动作重新执行原版数值逻辑，另用帧级战斗模型复核真实抽样，不依赖束搜索的支配或区域压缩。

## 暴露并修正的问题

1. 自然开场数值初态曾扣掉黄钥匙，却保留了序章黄门。首次返回序章的真实回放在该处停止；已同时清除门和原始出生标记，修正后续钥匙数并重新回放。旧M8禁止返回序章，所以其已验证结果不受影响。
2. 道具提示框的关闭按键包含实际状态修改。现已静态提取原版Space按钮，并在数值模型执行它，避免漏掉十字架、图鉴、飞行等标记。
3. 原版脚本表明隐藏结局存在不可逆顺序：先以未交十字架状态交神秘宝物取得冰杖/隐藏结局标志，再交十字架。提前交十字架会令仙子离开且缺少隐藏结局标志。相应原版字节码反事实测试已通过；该顺序尚待完整24层真实路线确认。错误的后段候选已回退，搜索加入顺序约束。
4. 原版剧情人物交互可能留下一个没有商店窗口的`Display_buy`标记。新按键回放以实际窗口、剧情和按键状态判断能否移动；不把遗留标记误判成仍在购买。

数值候选已按隐藏结局顺序完成十六层神秘宝物、仙子、十字架剧情，进一步取得十二层开路道具并完成小偷第二次开路。后半程尚未在真实播放器中完整验证，不能与十一层的实测结果混同。

搜索现在检查目标敌人的战斗门槛与最不利伤害，避免把“已走到Boss旁边”误报成可战胜它。当前中后程资源分配仍需改进：可行候选尚未接通十八层公主及完整结局，搜索失败不证明无解。

## 复现入口与边界

公开证据可先独立重建数值动作并逐战复算；这一步检查数值一致性，不能凭公开收据本身证明私有实测轨迹真实性或无观测器等价。已有固定原版、依赖及官方播放器后：

```sh
# 独立核对公开的665动作/107战斗，并重建可供真实播放器执行的候选
python3 tools/verify_route_progress.py experiments/full-route-prefix11.json generated/private/mhhf.swf --proposal-out generated/FullRoute/proposal.json
# 以下命令另行生成启发式续程，会覆盖本地候选。
# 可能在尚未找到候选的检查点报错，不能理解成无解
python3 tools/explore_full_route.py generated/private/mhhf.swf --width 512
# 继续本地已生成候选，先重新执行既有动作核对资源
python3 tools/explore_full_route.py generated/private/mhhf.swf --resume --width 512
# 真实时钟/自然随机数回放当前候选
python3 tools/fullgame_observer.py
node tools/fullgame_replay.mjs
# 复核已经执行的动作、资源、门槛、特殊预伤及抽样
python3 tools/audit_fullgame.py
MOTA_FLASH_SWF=generated/private/mhhf.swf npm test
```

本轮4项Node和59项Python测试通过；CI另行重建公开数值收据。测试包含原版剧情节点、自然开场门、钢剑真实+70、16层敌人变更只触发一次、十字架关闭按钮及隐藏结局顺序。剧情测试使用明确数值夹具，不能当作真实通关证据。现有M4/M5/M6/M7/M8基准继续回归。

后续验收仍是完整24层结局、可复验的同规则超纪录成绩；对照、版本兼容和纪录现状复查在宣称破纪录前必须完成。当前目标保持进行中。
