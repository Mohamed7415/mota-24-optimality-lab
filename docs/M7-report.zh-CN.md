## 商店自身不会制造无限资源的论证

在非负、精确整数的金币/钥匙/经验域内，定义：

`P = 金币 + 10×黄钥匙 + 50×蓝钥匙 + 100×红钥匙 + 经验`

`R = P(P+1)/2 + 金币`

有 `0 ≤ 金币 ≤ P`。对资源发生变化的成功交易：

- 买钥匙保持P，降低金币，因此R下降。
- 卖钥匙令P分别下降3/15/30；金币可上升，但仍不超过新的P。
- 金币和经验升级均降低P。
- 对任何较小的P，最大的R也小于原P区间最小的R，因为
  `(P−1)P/2 + (P−1) = P(P+1)/2 − 1`。

所以每个改变资源的商店交易都严格降低非负整数R。没有外部奖励输入时，成功交易总数的粗界为初始R，
商店组合无法形成资源增益循环或无限次资源变化。交易失败、退出和纯菜单操作是恒等步骤，抽象时合并。
这项论证不依赖216个样例覆盖所有整数；样例用于验证所引用的实际例程与模型一致。

该论证绑定精确整数域，未采用编辑存档、Infinity或超出精确整数范围的资源。
要把它变成全塔有限性证明，还须证明敌人、道具、剧情奖励等外部输入有界且不能重复刷取，
并覆盖其他全部规则。**全塔有限状态模型仍未完成**。

## 实际路线与持久化

M6的自然开局保持不变：MT1初入钥匙为0/1/1，指定种子首次上楼梯为860HP。
之后沿MT2左通道进入三层。路线各阶段如下：

| 检查点 | HP/攻击 | 金币/经验 |
|---|---|---|
| 第一次到达MT2 | 860/10 | 4/4 |
| 三层左区取得铁剑 | 215/20 | 16/15 |
| 返回一层取得血瓶与红宝石 | 310/23 | 21/19 |
| 再到三层，打开金币商店前 | 105/23 | 34/31 |
| 实际支付25金币买800生命 | 905/23 | 9/31 |
| 再次返回一层 | 905/23 | 9/31 |

跨层扩展包含7次楼层切换、18个消费事件和1次商店购买；加上M6前缀共31个事件。
全部115次勇士攻击抽样与固定Ruffle种子128188416的连续序列相等。
23个消费格包括M6前缀5格与扩展18格；最终通过只读观测读取原版地图数组，全部仍为0。
这支持这条具体路线的敌人/门/道具持久化，没有将其推广到全部27地图和剧情奖励。

本路线使用有限敌人、道具、钥匙及金币；905是不同终点/动作集合下的可行值，
不能与M6“首次上楼梯、不跨层绕行”的860/965混作同一优化目标。
本次没有给三层或全塔HP上界，也没有宣称路线最优。
