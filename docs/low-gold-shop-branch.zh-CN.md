# 减少金币商店购买的分支（未破纪录）

这是另一条真实搜索分支，仍采用固定2018存档的原版字节码数值模型。它不证明H5可行，也没有原版实际结局。

## 已跑出的数值前缀

[164次金币商店购买的收据](../experiments/gold-shop164-stat-prefix.json)通过到原攻略1711号动作，已进入最后一层、尚未攻击最终Boss。数值为28568血、4002攻、5005防、6638金币、1080经验。原参考路线是218次金币属性/血量购买；本分支省去后段54次金币防御购买，把前段7次金币攻击改成防御，并把最后51次经验攻击改成防御。

最终Boss的99999血、5000攻、4000防来自同SHA存档的[实际原版观测收据](../experiments/full-route-native-gdut-hp28568.json)，没有凭空补敌人数值。独立非暴击公式得到每击2点、50000击、零受伤；这是最后一战的公式检查，**没有执行这场战斗的完整字节码或实际影片**。现有逐战VM还有20000回合限制，不能把公式检查升级成完整回放。

当前H5榜单的金币商店最少购买为161、金币最多为6660，均属于另一构建。这里的164/6638既没有越过那些数值，也没有建立同规则比较。这个结果只提供一个接近的搜索起点。

## 尝试160次购买的三个分支

[三次实际试验](../experiments/gold-shop160-level-trials.json)尝试用5层付费升级代替三个大经验购买批次，末段仅留两次金币血量购买，同时从不同位置把金币防御改买攻击。三次都未接到完整结局：

| 防御转攻击起点（源动作） | 停止处 | 数值模型反馈 |
|---|---|---|
| 1087 | 25层1373号动作 | 当前配置无法触发目标战斗 |
| 980 | 17层1027号动作 | 当前配置无法触发目标战斗 |
| 930 | 17层952号动作 | 当前配置无法触发目标战斗 |

失败只适用于这三个顺序/购买策略，不能推出160次全局不可能。需要继续改变更早的资源安排、血量取得时机或路线。

## 复验

准备已固定SHA的2018原版文件后，在仓库根目录运行：

```sh
python3 tools/search_gold_shop_stat_candidate.py --swf generated/private/gdut-v112.swf --out generated/GoldShopStatRecheck
python3 tools/search_gold_shop_level_trials.py --swf generated/private/gdut-v112.swf --out generated/GoldShopLevelsRecheck
```

输出目录必须是新目录。原版文件、原图、完整地图和私有数值草案不随报告上传。
