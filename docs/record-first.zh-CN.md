# 当前目标：先找到可验证的24层破纪录路线

2026-10-23，用户将主目标改为：先找到一条可验证、能破世界纪录的完整24层路线，并授权“哪条能破纪录就找哪条”。血量、攻防和、得分、用时均可，依实际突破机会选择；不要求先证明全局最优。

## 当前真实完成度

M8以前的规则核验和局部路线继续作为工具使用。项目目前只验证过前三层内的具体路径；尚未有完整24层通关回放，也没有可宣称破纪录的路线。下一实质里程碑必须推进完整通关，不再以一层局部最优或三层回程HP提升替代。

原版优先。原版Flash、H5复刻、Tap移植、修改版及不同结局分别建档，不能用一个版本的超分对比另一个版本。具体版本最终要有文件或源码指纹；“V1.12”标签不足以证明规则相同。

## 执行顺序与验收

1. 先把已有完整文字路线转成结构化动作与检查点，复现一次真实完整通关。该路线作为起点，不固定M6前缀；没有逐步复验前不把攻略数值当模型真值。
2. 同时记录最终HP、攻防和及用时；优先重分配经验/金币、取物和战斗顺序，在已经能通关的路线上寻找严格改进。采用启发式和局部改良，无须先穷尽全塔。
3. 候选在未修改游戏中从新开局走到明确结局，保留完整输入、资源变化和必要的独立对照。披露程序辅助、随机种子、时钟、存读档、剪辑等。
4. 比较前复查同版本同规则的最新公开最高成绩。不同结局、约束HP与无约束HP、真人速通与程序回放分开。
5. 明确区分“找到改进候选”“独立复验超分”“超过已核实公开最高”“平台认可世界纪录”。在实际满足前不升级表述。

初步优先选择原版的完整属性/血量路线，因为已有完整文字基准且现有工具能核对资源；这只是基于现有工具的工程判断，不是已经证明该赛道最容易破。H5的10090作为独立候选与资源线索。真人速通先审阅规则，当前固定日期的程序回放不能直接声称真人RTA破纪录。

全塔有限性、上界、全局最优证书保留为后续研究；只有某项核验阻碍完整路线或合法比较时，才优先继续做它。社区投稿或联系他人不由本目标自动授权。
