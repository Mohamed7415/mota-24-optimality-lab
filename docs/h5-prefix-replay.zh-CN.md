# 独立复验自有H5十层前缀

[录像文件](../experiments/h5-prefix360-own.h5route)来自本项目自己的普通输入游玩，不含地图或游戏媒体。[验证收据](../experiments/h5-prefix360-independent-replay.json)给出SHA256、实际加载的JavaScript响应指纹及检查范围。

在[官方24层页面](https://h5mota.com/games/24/)的开始菜单选择“录像回放”，打开这个 `.h5route` 文件。开场自动播放后，按空格开始回放；可以按数字6使用官方24倍速度。无需载入本项目的存档，也无需修改游戏变量。

完成后应显示“录像播放完毕”，进度4164/4164（100%）；画面在10层，856血、185攻、108防、1级、376金币、21经验、钥匙4/7/1。原录像的模式选择保留在文件里，战斗暴击标志为关闭。

本项目已在全新浏览器资料中实际完成这次复验，读取被动引擎状态并单独目视检查终点及完成提示。仅向播放器发送开始、选文件、空格和数字6；没有逐格手动补走。游戏按正常录像机制使用文件中的原始自然种子，这与直接改随机种子不同，但必须披露。

这是360源动作的前缀，不是24层通关，没有提交成绩或取得纪录。实际JS指纹也不等于历史榜单每位玩家的构建身份。24倍回放速度不作为真人速通成绩。

另已导出[600动作自有录像](../experiments/h5-prefix600-own.h5route)，终点9层、614血/355攻/404防、104金币/524经验、钥匙16/8/1；[实跑收据](../experiments/h5-normal-ui-prefix600.json)。600录像也已在另一个全新浏览器独立回放成功，实际进度7390/7390（100%）；[验证收据](../experiments/h5-prefix600-independent-replay.json)。
